# IONYX Framer Clone

Exportierbarer React/Vite-Clone der Framer-App
`https://logical-share-233457.framer.app/`.

## Status

`incubating`

## Ziel

Die oeffentliche Framer-Seite als eigenstaendige Web-App nachbauen, damit sie
lokal bearbeitet, gebaut und spaeter gehostet werden kann.

## Umfang

### Enthalten

- Home, About, Blog, vier Blogartikel, Contact, Privacy Policy, Cookie Policy
  und 404.
- Header, Footer, Abschnittsnavigation, CTA-Bereiche und Kontaktformular.
- Dunkles AI-Agency/SaaS-Design mit responsivem Layout.

### Nicht enthalten

- Exakter Framer-Editor-Export oder Framer-interne Runtime.
- Backend-Versand fuer Kontaktformular-Daten.

## Entwicklung

```powershell
npm install
npm run dev
```

## Abnahme

- [ ] Alle erkannten Seiten und Formulare sind lokal vorhanden.
- [ ] `npm run build` laeuft erfolgreich.
- [ ] Desktop- und Mobile-Layout sind visuell geprueft.
- [ ] Offene Abweichungen zur Framer-Quelle sind dokumentiert.
